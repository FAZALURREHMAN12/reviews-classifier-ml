# Reviews Classifier

### Overview
A Natural Language Processing (NLP) machine learning model designed to analyze and classify text-based reviews. It categorizes user feedback into sentiments by extracting features from raw text data.

### Technologies Used
* Python
* Scikit-learn
* Natural Language Processing (NLP)

### Key Features
* Cleaned and tokenized raw text data for feature extraction and analysis.
* Trained classification models to accurately predict user sentiment.
* Evaluated model accuracy, precision, and recall using core data science libraries.
